# NetSwitcher - 网卡 IP / 系统代理一键切换工具

绿色单文件工具（约 58KB），支持 Win7 / Win10 / Win11（需 .NET Framework 4.0+ 运行时，Win7 若无请安装 Microsoft .NET Framework 4.0 或更高版本）。Win11 风格界面，亮/暗色自动跟随系统，高 DPI（125%/150%）下自动等比缩放不溢出。

## 功能总览
- **方案切换**：网卡 IP 方案与代理方案分开保存、分开应用；托盘菜单一键切换
- **四段式 IPv4 输入**：IP 地址、子网掩码、网关、DNS1/DNS2 全部采用四段式输入框（每段 0-255、满 3 位或输入"."自动跳格、粘贴自动过滤），保存/应用前全量校验
- **子网掩码预设**：预设下拉一键填入标准掩码（/8 ~ /32 全覆盖），也可在四段框中手动输入
- **托盘常驻**：关闭主界面即缩到通知栏；左键/右键弹菜单（切换方案、随系统启动、退出），**双击图标**打开主界面
- **随系统启动**：主界面"随系统启动"勾选框（或托盘菜单），写当前用户注册表，无需管理员额外配置
- **网卡操作**：一键启用 / 禁用 / 重启网卡；一键打开 网卡状态窗口、网卡属性（网络连接中定位选中）、IP 设置窗口（自动区分 Wi-Fi / 以太网）
- **网卡下拉列表**：显示每块网卡的连接状态与启禁用状态（含已禁用的网卡），启用的排前面
- **获取当前设置**：从所选网卡读取 IPv4/IPv6/DNS/代理回填编辑区，获取后仍可任意修改再应用或保存
- **多套方案**：INI 文件保存在 `profiles` 文件夹，支持导入 / 备份全部

## 使用
1. 双击 `NetSwitcher.exe`，UAC 弹窗选"是"（修改网卡 IP 必须管理员权限，已内置于程序）
2. 左侧选择方案类型（网卡IP方案 / 代理方案），双击列表中的方案载入编辑区
3. 右上选择目标网卡，编辑 IPv4 / IPv6 / DNS / 代理，点 **一键应用**
4. 或点 **获取当前设置** 快速捕获当前网络配置 → 修改 → 另存为方案
5. 关闭窗口 → 程序常驻通知栏；从托盘菜单切换方案会弹气泡提示

## 方案类型说明
- **[IP]**：应用 IPv4 / IPv6 / DNS 设置（不碰代理）
- **[代理]**：只应用系统代理开关与服务器（不碰 IP）
- **[完整]**：旧版本创建的方案，两者都应用（兼容保留）

INI 中以 `[Profile] Type=IP|Proxy|All` 区分。

## 方案文件格式（INI）
保存在 exe 同目录 `profiles\方案名.ini`：

```ini
[Profile]
Name=办公网
Type=IP             ; IP / Proxy / All
[Adapter]
Name=以太网
[IPv4]
Mode=Static          ; DHCP 或 Static
IP=10.1.20.35
Mask=255.255.255.0
Gateway=10.1.20.1
DNS1=10.1.1.8
DNS2=114.114.114.114
[IPv6]
Mode=Auto            ; Auto 或 Static
IP=
Prefix=64
Gateway=
[Proxy]
Enabled=0            ; 1 启用系统代理
Server=127.0.0.1:7890
BypassLocal=1
```

## 重新编译（可选）
源码在 `src\NetSwitcher.cs`，编译不需要安装任何开发工具，
双击 `src\build.cmd` 即可（调用 Windows 自带的 .NET Framework 编译器）。
图标由 `src\make_icon.py` 生成（Pillow），如需换图标改脚本后重跑，再执行 build.cmd。

## 注意事项
- **Win7 差异**：「状态」和「IP设置」窗口依赖 Win8/Win10 组件，在 Win7 上会自动回退打开传统「网络连接」控制面板；其余功能完全一致
- 主题在启动时读取系统设置；切换系统亮暗模式后重启本程序即可同步（Win7 无系统级暗色，始终为亮色）
- IPv6"自动获取"依赖路由器的 RA / DHCPv6，部分网络环境需实测
- 系统代理是 Windows 全局设置（当前用户），不区分网卡
- 禁用网卡后该网卡仍会出现在下拉列表中（状态显示"已禁用"），可再点"启用"
- 若被杀毒软件误报，将 exe 所在目录加入白名单即可（程序未签名属正常现象）
